# Ritmo Launcher (Deprecated)

⚠️ **WARNING: This launcher is not part of the current distribution model.**

The ritmo_launcher was designed for a portable distribution system that is no longer being actively developed. The project currently focuses on standard system installations using the CLI.

## Current Status

- **Not Ready for Users**: The launcher is incomplete and not part of the current release strategy
- **Use CLI Instead**: For library management, please use the `ritmo_cli` command-line interface directly
- **No Active Development**: This component is not currently being maintained

## For Reference Only

This crate was designed to:
- Provide a launcher for portable Ritmo installations
- Handle automatic library detection and verification
- Download binaries from GitHub releases
- Launch the GUI application

However, these features are not currently supported in the main distribution model.

## For Developers

If you need to build the entire workspace including this crate, it will compile but is not intended for end-user use.
