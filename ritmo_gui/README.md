# ritmo_gui - GUI (Early Development)

⚠️ **WARNING: This GUI is in early development and not ready for users.**

The GUI for ritmo is being developed using the egui framework. It is currently in an experimental phase and not yet integrated with the current command architecture.

## Current Status

- **Not Ready for Production**: The GUI is incomplete and under active development
- **Use CLI Instead**: For stable functionality, please use the `ritmo_cli` command-line interface
- **No Documentation**: Full documentation will be provided when the GUI reaches a stable state

## For Developers

If you are a developer interested in contributing to the GUI:

1. The GUI uses the egui framework
2. Architecture is designed to be contents-centric
3. Integration with `ritmo_commands` is planned but not yet complete

Please check the main project documentation and development guide for building from source.
